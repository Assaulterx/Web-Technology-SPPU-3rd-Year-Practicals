Sr. No. Website URL Purpose of the website Things liked in the website Things disliked in the website Overall Evaluation
1. https://www.google.com Search engine for finding information, websites, images, videos, and more. Simple interface, fast results, powerful search suggestions, and relevant filtering options. Home page is very minimal and can feel too plain; a lot of data collection for ads. Excellent for quick information retrieval and everyday use.
2. https://www.youtube.com Video sharing and streaming platform for education, entertainment, and content creation. Huge content library, good recommendation system, and support for creators. Too many ads on free account and sometimes distracting homepage recommendations. Very useful platform but can be overwhelming without personalization.
3. https://github.com Code hosting and collaboration platform for developers using Git. Clean repository view, good issue tracking, pull requests, and integration with CI/CD tools. Can be confusing for complete beginners; some advanced features are hidden in menus. Great tool for version control and open-source collaboration.
4. https://stackoverflow.com Q&A site for programming and technical questions. High-quality answers, voting system, and wide coverage of programming topics. Some older answers maybe outdated; community can feel strict to new users. Essential resource for developers troubleshooting code.
5. https://developer.mozilla.org Documentation and learning resources for web technologies (HTML, CSS, Javascript, etc.). Detailed documentation, clear examples, and up-to-date browser compatibility tables. Some pages are long and dense, which can be hard to skim quickly. Excellent reference site for web development.
6. https://www.w3schools.com Tutorial website for learning basic web development and programming concepts. Begginer-friendly examples, interactive editor, and simple naviagtion. Some explainations are oversimplified; not always the most modern practices. Good starting point for beginners learning web technologies.
7. https://www.linkedin.com Professional networking platform for jobs, connection, and sharing achievements. Strong profiule structure, job recommendations, and networking features. Feed can feel cluttered; many notifications and sponsored posts. Very useful for career growth and professional visibility.
8. https://www.medium.com Blogging platform for writers to publish and stories. Clean reading experience, good typography, and topic-based discovery. Paywall limits the number of free articles; sometimes too many generic posts. Good platform for long-form reading and writing.
9. https://www.netflix.com Streaming serivce for movies, series, and documentaries. Easy-to-use interface, personalized recommendations, and high-quality streaming. Content library varies by region; sometimes hard to discover niche content. Great for entertainment with a smooth user experience.
10. https://amazon.in E-commerce platform for buying a wide variety of products online. Wide product range, fast delivery options, and detailed reviews. Homepage can feel busy; sponsored products sometimes appear before relevant results. Very convienient for online shopping with reliable service.
